# 🍽️ Restaurant Website

A modern and responsive restaurant website designed and developed using HTML5 and CSS3.

## 📌 About the Project

This project is a restaurant website that showcases a clean and attractive user interface. The website includes multiple pages such as a Home page, Menu page, About Us page, and Contact page.

HTML5 is used to create the structure and content of the website, while CSS3 is used to style and design the pages.

## ✨ Features

- 🏠 Home Page – Introduces the restaurant and highlights its services.
- 🍴 Menu Page – Showcases the available food items.
- 👨‍🍳 About Us Page – Provides information about the restaurant.
- 📞 Contact Page – Provides contact and location information.
- 🔘 Interactive Buttons – Buttons are used for navigation and user interaction.
- 🎨 Custom Styling – Colors, fonts, borders, spacing, and other CSS properties are used to create an attractive design.
- 📐 Website Layout – Different layouts and positioning techniques are used to organize the content.
- 📱 Responsive Design – The layout is designed to work across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 What I Learned

Through this project, I learned how to structure a multi-page website using HTML and style it using CSS. I also practiced creating buttons, layouts, navigation, typography, spacing, colors, and other styling elements.
